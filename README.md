# hardworkREC

## 1.0.13 · 화면 디자인 개선

- 밝은 배경·네이비·라임 색상과 통일된 카드, 입력칸, 터치 효과를 적용했습니다.
- 메인 요약 카드에서 오늘 기록 수·입력한 운동 시간 합계·이번 달 운동한 날짜 수를 확인합니다. 카운트·타이머는 별도의 도구 카드로 제공합니다.
- 아이콘이 있는 하단 탭, 기록 카드와 빈 화면, 달력 선택 표시, 앱 아이콘을 새로 구성했습니다. 개인정보·권한 안내는 메인 오른쪽 위 정보 아이콘에서 엽니다.
- 카운트·타이머를 스크롤할 수 있어 작은 화면과 큰 글씨에서도 하단 버튼에 접근할 수 있습니다. 기존 기록 저장, 리셋 확인 방식과 백업 동작은 유지합니다.
- 이 버전은 기존 설치와 호환되는 **debug 서명 APK**로 배포합니다. 스토어 판매용 서명·판매자 설정이나 스토어 출시 완료를 뜻하지 않습니다.
- 새 아이콘은 앱 내부에서 직접 그리는 도형이며 외부 이미지·폰트·런타임 의존성을 추가하지 않았습니다. 기존 개인정보·제3자 고지를 유지합니다.

## 기능

- **오늘**: 운동명 추가, 오늘의 기록과 합계 확인, 운동 기록 시작
- **기록**: 팝업에서 운동 선택, 자유 텍스트로 여러 세트의 횟수 입력, 시간 한 칸 연속 입력 (`125` → `1:25`, `1234` → `12:34`). 오늘의 기록에서 운동명과 횟수를 바로 수정할 수 있습니다.
- **카운트**: 메인 최상단에서 진입. 중앙 원형 버튼을 누를 때마다 1 증가, `−1`, 빠르게 두 번 누르는 리셋, 진동·소리 토글 제공. 운동 기록과 독립된 도구입니다.
- **타이머**: 기본 60초, 초 단위 설정·표시. 중앙 원형 버튼으로 시작/일시정지/재개, 입력한 설정 시간으로 리셋. 만료 진동·소리 토글은 기본 진동 ON·소리 OFF입니다.
- **달력**: 운동한 날짜에 점 표시. 날짜를 누르면 해당 날짜의 기록 표시
- **백업**: Android 파일 선택기로 JSON 백업 저장·가져오기. Google Drive에 보관하려면 저장 위치에서 Drive를 선택해야 합니다. 가져오기는 기존 기록을 보존하고 UUID 기준으로 중복을 건너뜁니다.

기록은 기기의 SQLite 데이터베이스에 저장됩니다. Android 시스템의 앱 데이터 자동 백업도 허용하지만, 자동 백업의 실행 시점·복원은 기기와 Google 계정 설정에 따릅니다. 앱의 백업 화면은 수동 백업입니다. **APK 자체는 Google Drive에 업로드하지 않습니다.**

## 빌드

JDK 17과 Android SDK 36이 필요합니다. `ANDROID_HOME`을 SDK 디렉터리로 설정한 다음:

```powershell
.\gradlew.bat --no-daemon lintDebug testDebugUnitTest assembleDebug
```

디버그 APK: `app/build/outputs/apk/debug/app-debug.apk`.

## 백업 형식

UTF-8 JSON `schemaVersion: 1`. 운동명과 기록 UUID·횟수·시간(초)·기록시각을 포함합니다. 가져오기 전 형식과 값을 검증하며 기존 데이터는 삭제하지 않습니다. 백업 파일은 암호화되지 않으므로 공유 위치는 사용자가 신중히 선택해야 합니다.
