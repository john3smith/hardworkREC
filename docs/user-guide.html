01

어떤 일을 하나요?

오늘의 기록

운동명 추가, 팝업 기록 입력, 오늘의 기록과 합계를 확인합니다.

직접 수정

메인 기록에서 운동명·횟수를 바로 수정하고 자유 텍스트로 여러 세트를 적습니다.

카운트·타이머

최상단 버튼으로 독립 화면에 진입합니다. 큰 원형 버튼, 진동·소리 토글과 리셋을 제공합니다.

달력·백업

날짜별 기록과 JSON 수동 백업·가져오기를 지원합니다.

02

처음 사용하기

  1. APK를 설치하고 메인 상단의 작은 운동명 추가 버튼으로 운동을 등록합니다.
  2. 운동 기록하기를 누른 뒤 팝업에서 운동과 횟수·시간을 입력합니다.
  3. 시간은 한 칸에 연속 입력합니다. 125는 1분 25초, 1234는 12분 34초입니다.
  4. 저장하면 오늘의 기록에 표시됩니다. 운동명·횟수는 해당 입력칸을 눌러 수정합니다.
  5. 달력 탭에서 운동한 날짜 표시와 그날의 기록을 확인합니다.
03

자주 쓰는 기능

카운터
큰 원을 누를 때마다 1 증가합니다. −1과 진동·소리 설정을 사용할 수 있고 리셋은 빠르게 두 번 눌러야 작동합니다.
타이머
기본 60초입니다. 초 단위 설정을 넣고 중앙 원으로 시작·일시정지·재개합니다. 설정시간으로 리셋은 입력한 값을 즉시 반영합니다.
만료 알림
타이머 기본은 진동 ON·소리 OFF입니다. 기기 음량·방해금지·하드웨어 상태에 따라 실제 알림을 확인하세요.
백업
Android 파일 선택기로 JSON을 저장·가져옵니다. 가져오기는 기존 기록을 유지하며 UUID 중복을 건너뜁니다.
04

문제가 생겼을 때

타이머 알림이 없습니다
진동·소리 토글, 기기 음량·방해금지 설정을 확인하세요. 에뮬레이터는 실제 진동을 확인할 수 없습니다.
카운터가 리셋되지 않습니다
실수 방지를 위해 리셋을 빠르게 두 번 눌러야 합니다.
백업에 Drive가 없습니다
Android 파일 선택기에 해당 저장 제공자가 있는지 확인하거나 로컬에 먼저 저장하세요.
05

데이터와 보안

  • 운동 기록은 내부 SQLite에 보관합니다. JSON 백업은 암호화되지 않습니다.
  • 시스템 자동 백업의 실행·복원 여부는 기기와 계정 설정에 따릅니다. 중요한 기록은 별도 백업하세요.
06

알아두실 제한사항

  • 카운터·타이머는 운동 기록과 독립된 도구입니다. 누른 횟수가 자동으로 운동기록에 저장된다고 가정하지 마세요.
  • 백업 화면은 수동 백업이며 Google Drive 자동 업로드나 자체 계정 동기화가 아닙니다.
  • 시간 입력 125는 125초가 아니라 기록 칸에서 1:25입니다. 타이머 설정은 이와 달리 초 단위입니다.
